# Claude.ai 作物素材生成指令

> **用途**：在 Claude.ai 网页版生成 38 个作物的 Hay Day 风格 SVG 美术。
> **一次性粘贴**这一份完整 prompt 就够了，不需要分批。

## 使用步骤

1. 打开 **Claude.ai**（建议用 **Sonnet 4.6** 或 **Opus 4.7**，**不要**用 Haiku，画图细节会打折）
2. 新开对话
3. **复制下面整段 prompt** 粘贴进去
4. Claude.ai 会用 **Artifacts** 一个一个渲染 SVG，你能直接在右侧预览
5. **如果它停下来问"要继续吗"**，就回复「继续」或「下一个」
6. **不满意的就单独追问**：「重画 huo_long_guo，鳞片要更突出」
7. 全部满意后，把所有 SVG 代码复制贴回这里（Claude Code）

⏱ **预计耗时**：2-3 小时（含迭代）

## 🎨 风格规则（全部 38 个都按这个）

**输出格式（强制）：**
- viewBox="0 0 100 100"
- **透明背景**（不要画背景色块、不要画土壤——游戏会自己加地块）
- 作物水平居中，底部在 y=88 左右
- 作物占满 70-85% 的垂直空间
- 所有渐变/滤镜 inline 在 `<defs>` 里
- **禁止**：emoji、文字、JavaScript、外部 CSS、`<image>` 引用

**视觉风格（Hay Day 风）：**
1. **柔和投影**：底部椭圆阴影 `fill="#000" opacity≈0.18`，配合 SVG drop shadow 滤镜
2. **高饱和色**：明亮鲜艳，但不要荧光
3. **多层渐变**：主体面用 `<linearGradient>` 2-4 个 stop（底深 → 中主色 → 顶亮）
4. **光照方向**：从左上方来
5. **高光叠加**：每个主要面加一个半透明白色椭圆（opacity 0.3-0.55），在左上位置
6. **细描边**：stroke-width 0.4-0.8 深色描边
7. **圆润胖嘟嘟**：比真实物体稍稍放大，可爱化
8. **全部 Bezier 曲线**（用 path d="M ... Q ..."），不用直线
9. **分层结构**：每个作物 5-7 层 path 叠加：
   - L1：地面投影椭圆
   - L2：主体深色底
   - L3：主体渐变色（用 `<linearGradient>`）
   - L4：表面细节（叶脉、纹路、点斑）
   - L5：半透明白色高光覆盖
   - L6：顶部反光点（小白椭圆）

**参考模板：**

```svg
<svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
  <defs>
    <filter id="ds" x="-20%" y="-20%" width="140%" height="140%">
      <feGaussianBlur in="SourceAlpha" stdDeviation="1.5"/>
      <feOffset dy="2" result="off"/>
      <feComponentTransfer><feFuncA type="linear" slope="0.35"/></feComponentTransfer>
      <feMerge><feMergeNode/><feMergeNode in="SourceGraphic"/></feMerge>
    </filter>
    <linearGradient id="bodyGrad" x1="0%" y1="100%" x2="0%" y2="0%">
      <stop offset="0%" stop-color="#深色"/>
      <stop offset="50%" stop-color="#中间色"/>
      <stop offset="100%" stop-color="#亮色"/>
    </linearGradient>
    <linearGradient id="shine" x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" stop-color="#fff" stop-opacity="0.5"/>
      <stop offset="100%" stop-color="#fff" stop-opacity="0"/>
    </linearGradient>
  </defs>
  <ellipse cx="50" cy="92" rx="22" ry="3" fill="#000" opacity="0.18"/>
  <g filter="url(#ds)">
    <path d="..." fill="url(#bodyGrad)" stroke="#深色描边" stroke-width="0.6"/>
  </g>
  <ellipse cx="40" cy="50" rx="10" ry="14" fill="url(#shine)"/>
  <ellipse cx="38" cy="40" rx="2" ry="3" fill="#fff" opacity="0.75"/>
</svg>
```
