# 等距可建造大地图改造 · 可行性与分期方案

> 目标（Chris 2026-06-15）：把农场从"竖排 3×4 地块"重做成 Hay Day 那种
> **等距（2.5D）可建造大地图**（参考 IMG_1655）。

## 一句话定性
这不是"换皮"，是**在现有游戏上叠加一套新的地图渲染引擎 + 摆放系统**。
现有全部机制（种/收/卖/社区/积分/云存档）作为"数据层"**全部复用**，
地图只是一个**新的"视图层"**。分期推进，每期可单独验收。

## 三大难点（按风险排序）
1. **美术资产（最大的坎）**。等距世界需要一整套**风格统一的等距素材**：
   地形瓦片、房子/谷仓/商店、动物、树/水/路/篱笆/装饰，几十到上百件。
   - Hay Day 是手绘等距插画；Gemini 生成等距素材**透视/比例/光照难统一**。
   - Chris 之前发的像素素材包（IMG_1628）是**俯视像素风**（非等距），但**素材现成、量大、风格统一**。
   - ⚠️ **关键决策**：走"等距插画(美术风险高、要解决素材来源)" 还是
     "俯视像素瓦片(用现成包、更快、同样是可建造大地图，Stardew 风)"。
     **引擎能写，但没有统一素材就是空壳——这一项决定整个项目能不能落地。**
2. **渲染引擎**。建议 **Canvas 2D** 画地图层（DOM 撑不住大地图 + 深度排序 + 平移缩放）；
   HUD/底部导航/弹窗仍用现有 DOM。等距需要：坐标换算（格→屏）、**深度排序**（前后遮挡）、
   相机平移/缩放、点击命中检测（屏→格）。
3. **手机性能 + 存档迁移**。Canvas 重绘要控制（脏矩形/分层）；地图布局要存
   `state.map[] = [{type, gx, gy}]` 并云端同步；老玩家需平滑迁移。

## 技术选型（建议）
- 地图层：**Canvas 2D**（单 canvas，相机平移，深度排序）。保持 vanilla、免构建。
- HUD/弹窗/导航：沿用现有 DOM（不重写）。
- 交互：tap 命中检测 → **复用现有** `Farm.shop.openSeedPickerForPlot` / `Farm.farm.harvestPlot` 等。
- 存档：新增 `state.map`（摆放数据）；地块仍用现有 `state.plots`，只是在地图上有坐标。
- 上线策略：**`?map=1` 开关**先并行存在，不动现有竖排农场，验收满意再切默认。

## 分期（每期可验收、可回滚）
**Phase 0 — 决策与规格（现在，0 代码）**
- 定美术方向（等距插画 vs 俯视像素），定瓦片尺寸/命名/Phase1 所需素材清单。
- 定地图尺寸、可摆放品类、存档格式。产出本文件 + 素材清单。

**Phase 1 — 引擎垂直切片（POC，用占位美术）**
- Canvas 画出地面网格 + 相机拖动平移 + tap 命中。
- 把现有 12 个地块画到网格上，**点地块→走现有种/收/卖逻辑**（证明引擎能接现有机制）。
- 放 1 个静态建筑（谷仓）+ 证明深度排序。
- 目标：**用占位图先证明"引擎 + 接现有玩法"可行**，再投入美术。`?map=1` 开关，不影响线上。

**Phase 2 — 建造/编辑模式 + 持久化** ✅ 已完成（2026-06-15）
- 🔨 建造按钮进入编辑模式：底部素材盘（谷仓/小屋）选物添加。
- 选中建筑：橙色描边 + ✕ 删除芯片；拖动移动（绿/红落点合法性高亮）。
- 落点校验 `_footprintFree`：不出界、不压地块、不压其它建筑。
- 深度排序（按底边 baseline）让高建筑正确遮挡。
- 布局存 `Farm.state.data.map = [{type,gx,gy}]`，随云存档 blob 自动同步。
- 仍由 `?map=1` 隔离，不影响线上竖排农场。
- 待补：更多可摆放品类（树/水/路/装饰/动物）——需美术素材。

**Phase 3 — 世界填充与打磨**（进行中）
- 已接入像素美术：土块/上海青4阶段/谷仓/小屋/温室/鸡舍/树。
- 地形：无缝草地纹理 + 可涂刷的小路/水塘（建造模式「地形」笔刷，存 state.mapTerrain），
  水/路边缘自动描深（岸线/路缘）。
- EP 商店**装饰**已搬上地图，且**可在建造模式拖动摆放**（首次自动摆位→之后拖动，存 d.gx/gy）。
- **生命/氛围**：~15fps rAF 动画循环（隐藏/弹窗时暂停）——季节粒子（春樱/夏蝶/秋叶/冬雪）
  + 宠物在原地小范围游走。
- **节日专属视觉**：春节顶部挂灯笼串（摆动）、中秋右上角发光月亮（由 Farm.events 驱动）。
- 待续：平移缩放手感打磨/过场动画（代码侧基本完备，后续主要靠美术补素材）。

**等距方向（Chris 2026-06-15 拍板「真·等距 Hay Day」）**
- 现状：俯视正交是默认；`?iso=1` 是**等距 2.5D 预览**（`src/js/mapview-iso.js`，
  `Farm.isoView`）——菱形草地网格 + 建筑/作物立绘按 (gx+gy) 深度排序，复用现有 state +

**Phase 4 — 迁移与收尾** ✅ 默认切换已完成（2026-06-15，指俯视版）

- `body.mapmode`：#farm 当 flex 占位，画布盖住 #farm 盒，保留顶栏/Lv·XP/底部导航。

## 现实预期
- 量级：**数周到数月**（取决于美术方向 + 投入），不是一次成型。
- 按项目「UI 改造工作流」：分期、每步截图验收、`?map=1` 隔离、随时可回滚到现状。
- **美术是节流阀**：我能写引擎、能整合现有玩法，但**无法稳定产出统一等距素材**——
  这块要么 Chris 的 Gemini 工作流定一套可复用模板，要么采用现成素材包（如像素包）。

## 建议的第一步
先做 **Phase 1 POC**（占位美术）：让你**亲眼看到**"地图 + 点地块种菜"能跑起来，
再决定砸不砸美术。POC 风险低、可丢弃、不动线上。
**唯一需要你先拍板的**：Phase 1 用哪种美术方向打底（等距插画 / 俯视像素包）。
