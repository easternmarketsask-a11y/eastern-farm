# 油画农户角色（2026-08-20，Chris 已口头批准产品层）

玩家、来访真玩家、菜摊客人都用同一套**油画小人**出现在等距农场上，
并演出走路、浇水、收获、摊前站着。画风跟房子和菜同一套。不造假名，
不上传照片，不改老存档的地 / 房子 / 菜地坐标。

## 已拍板

| 项 | 决定 |
|---|---|
| 谁出现 | 所有人：农场主、拜访客、菜摊客人 |
| 样子 | 油画小人，不是色块火柴人，不是照片头像 |
| 款数 | 9 款固定人设；第一版不另做上衣五色 |
| 动作 | 走路、浇水、收获、摊前站着（站着也用于闲时） |
| 玩法时机 | 浇水/收获的数值立刻生效；人随后把动作演出来 |
| 默认 | 未选过 → 女农户（id 2） |
| 匿名路人 | 男农户（id 1） |
| 乡路行人 | 不加回来（`SHOW_COUNTRY_ROAD` 仍默认关） |

否决的做法：色块升级、一人一脸生成、会员自拍贴脸、第一版种菜/建造动作。

## 九款人设

菜单九宫格，从左到右、从上到下：

| id | 中文 | English | 要一眼能分开的特征 |
|---|---|---|---|
| 1 | 男农户 | Farmer (man) | 草帽、工作衫、成年男 |
| 2 | 女农户 | Farmer (woman) | 围裙、束发、成年女（新号默认） |
| 3 | 青年男 | Young man | 短发、夹克或卫衣，明显比 1 年轻 |
| 4 | 青年女 | Young woman | 马尾或短发，日常衣，不是围裙农户 |
| 5 | 男孩 | Boy | 儿童身高（约为成人 0.75），短发 |
| 6 | 女孩 | Girl | 儿童身高，辫子或bob，裙子或罩衫 |
| 7 | 爷爷 | Grandfather | 白发或花白、稍驼、宽松外套 |
| 8 | 奶奶 | Grandmother | 花白发髻、开衫或夹袄 |
| 9 | 店员围裙 | Shop apron | 超市绿围裙/工作服，和田里农户拉开 |

标签只用于选形象，**不是人名**。场上名字仍是会员昵称/真名，对不上就叫「路人」。

验收：九张站立图并排，不看标签也能分成九个不同的人；儿童明显矮一截。

## 人在场上怎么动

**自己的农场**

- 始终有一个农户，用存档里的 `farmerLook`（1–9）。
- 闲着：在自家草地格子之间慢慢走。不踩已解锁菜地、不踩建筑占地、不下水塘。玩家自己刷的小路可以走。
- 点正在长的菜：地里浇水立刻生效（现有 `waterPlot`）。人走到那块地，播浇水动作，播完回到闲逛。
- 点熟菜：收获立刻生效（现有 `harvestPlot`，连击/仓库/音效都不改）。人走到那块地，播收获动作，播完闲逛。
- 连点多块地：只演**最后**点的那块。不排队演完每一块（避免手机上人来回赶路挡操作）。
- 建造模式：人还在，但不参与点选命中。格子、建筑、菜地怎么点还怎么点。

**菜摊客人**

- `Farm.stall.customer()` 有人时，摊前画对应形象的「站着」，头上仍是现在的求购气泡。
- 真玩家客人：用其公开档案里的 `farmerLook`；没有该字段则用账号稳定映射到 1–9。
- 匿名：id 1。显示名规则不变（真名/昵称或「路人」）。

**拜访**

- 进别人的农场，农户用**那家**的 `farmerLook`。客人在自己场上的闲逛/浇水收获不在拜访场演出（拜访仍是看那家的地和建筑）。
- 不把沿乡路走的路人加回来。

## 贴图

每人设一张精灵表，透明底，不含烘焙草地、不含落地长影（游戏里用现有 `_shadow`）。

- 路径：`src/assets/images/farmers/p_farmer_{id}.webp`（id 1–9）
- 表：4 行 × 6 列，无分割线。行序固定：`idle` / `walk` / `water` / `harvest`。
- 角色脚底对齐每一格同一条基线，方便按列宽裁切。
- 透视：¾ 侧面，和房子、菜一致。只画朝画面右前方的一侧；朝左用水平镜像。
- 站立/等客播 `idle`（可循环）；走路播 `walk`（腿必须轮流迈，末帧接得回首帧）；浇水手臂真的在倒水；收获手臂真的在摘。
- 儿童（5、6）同一套动作，画布里人更矮，不要把成人缩小充数（头身比必须是孩子）。

生成管线（实现时用，不进玩家存档）：站立底图 → 视频做出走/浇/摘 → 抽 6 帧能循环的 → 抠透明底 → 拼表。四角 alpha 必须为 0。叠在草地 `#7eaa3d` 上不能出现黑方块（汽车贴图的教训）。

## 运行时

新的一块状态只活在内存（不写存档），由等距视图每帧推进：

- `look`：1–9
- `gx, gy`：浮点格子坐标（走过去要插值）
- `face`：`'l'` | `'r'`
- `anim`：`idle` | `walk` | `water` | `harvest`
- `frame`、`task`：当前要走到哪块地、到了播哪套动作

深度排序：和建筑、菜地一起按 `gx+gy` 画，人站在某格时不要穿到屋顶前面或菜后面。

点击逻辑：先命中菜地/建筑/装饰（现有顺序），农户精灵不抢点击。

预缓存：9 张表加入 service worker 预缓存清单。漏一张 = 那款人永远走网络。

## 存档与同步

本地 `eastern_farm_save_v1` 增加：

```
farmerLook: 2   // 整数 1–9；缺省或非法 → 2
```

不升 `save.version`（标量缺省即可，与 `petsEnabled` 同类）。禁止为此搬 `landOrigin` / `map` / `plots` / `clearedCells`。

公开 `farm_players/{uid}.gameStats` 增加同名字段 `farmerLook`，随现有 60 秒防抖一起推。拜访和菜摊客人读这个数。游客/没登录不写云。

选形象：设置 → 农场显示，九宫格。点即存、即换场上的人。不弹强制向导。文案短、完整句，不卖萌。

账号映射（公开档案没有 `farmerLook` 时）：对 uid 做稳定哈希，得到 1–9。同一 uid 每次相同。

## 手机与性能

- 场上常规：1 个农户 + 0/1 个摊前客人。
- 表按显示高度缩放（人比房子矮、比鸡狗高；儿童再矮一截）。
- 动画约 8–12 fps，足够认动作，不和 30fps 宠物抢。
- 贴图加载失败：该形象退回现有色块 `_drawVillager`，游戏能玩，不要白屏。

## 明确不做（第一版）

- 上衣五色、一人一脸、照片头像
- 种菜、建造、推车、挥手等额外动作
- 拜访时在别人地里演自己的浇水收获
- 恢复乡路和沿路行人
- 改经济、改 4 块免费地、改 `USE_PAINTED_BG`

## 验收

1. 自己农场能看见油画农户；闲时在草地走，不踩菜地和房子。
2. 点浇水：地立刻浇上；人走到该地做浇水动作。
3. 点收获：菜立刻进仓（连击仍在）；人走到该地做收获动作。
4. 连点两块地：人只去后点的那块。
5. 设置九宫格能换成 9 款，换完场上的人立刻变；刷新后还是这款。
6. 菜摊有客人时摊前是油画人 + 原气泡，不是色块人。
7. 拜访别人：看到的是那家选的形象（或哈希后的稳定形象）。
8. 九张表叠在草地上无黑底方块；儿童两款明显比成人矮。
9. 老存档的摊、仓、田坐标与改前一致。
10. `node --check` 相关 JS 通过；手机 360px 宽上人能认出在走、在浇、在摘。
