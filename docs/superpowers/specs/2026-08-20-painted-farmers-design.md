# 油画农户角色（2026-08-20）

自己的农场、拜访别人的农场、菜摊前的客人，都用同一套油画小人。
动作：走路、浇水、收获、站着等。画风跟房子和菜同一套。

不造假名、不上传照片、不改老存档的 `landOrigin` / `map` / `plots` / `clearedCells`。
`USE_PAINTED_BG` 保持 `false`。乡路行人加不回来。

## 时间轴（Chris 2026-08-20 改：做完动作才算完成）

人走到、把动作做完，这件事才生效。摘菜：人摘下手，菜才进谷仓。浇水：人倒完水，缩短时间才写入。

点选流程不变（点熟菜排队摘；点生长中仍开打理窗，窗里点「浇水」才排队去浇）。变的是**生效时刻**。

| 玩家做什么 | 人怎么做 | 何时生效 |
|---|---|---|
| 点一块熟菜 | 排进任务：走过去，做摘 | 摘的动作播完 → `harvestPlot` 进仓、音效、连击 |
| 再点别的熟菜 | 排在后面，一块一块做完 | 每块都是走到、摘完，才进仓 |
| 打理窗点浇水 | 关窗，排进去浇 | 倒水动作播完 → `tending.waterPlot` |
| 仓到那块地时已经满了 / 菜没了 | 人走到后做不了 | 不进仓，toast 与现在仓满相同，做下一项 |
| 点空地 / 施肥 / 加速 | 人不管 | 仍是点了就生效（第一版没有对应动作） |
| 建造模式 | 人还在，不抢点击 | 队列暂停，退出建造再接着做 |
| 拜访点熟菜 / 点生长中 | 那家农户只闲逛 | 顺菜、帮忙浇水仍立刻生效（你没有把人派过去） |
| 菜摊卖菜 | 客人站着等 | 窗口里成交，第一版你的农户不过去交货 |

连点熟菜是**队列**，不是只做最后一块。同一块地不重复排队。队列上限 = 当前已解锁菜地数。

连击：按**摘完进仓**的时刻算，两块相邻、走得近，仍可能连上；隔得远、走得久，连击会断。这是时间轴改完后的自然结果，不另做假连击。

菜在人走到之前一直还长在地里。不要先空地再演戏。

## 九款人设

设置 → 农场显示，九宫格。从左到右、从上到下：

| id | 中文 | English | 必须一眼不同 |
|---|---|---|---|
| 1 | 男农户 | Farmer (man) | 草帽、工作衫。匿名路人用这款 |
| 2 | 女农户 | Farmer (woman) | 围裙、束发。新号没选过用这款 |
| 3 | 青年男 | Young man | 比 1 年轻，夹克或卫衣，不戴草帽 |
| 4 | 青年女 | Young woman | 日常衣，不是田间围裙 |
| 5 | 男孩 | Boy | 儿童身高（成人约 3/4），短发 |
| 6 | 女孩 | Girl | 儿童身高，辫子或齐耳发 |
| 7 | 爷爷 | Grandfather | 花白发、稍驼、宽松外套 |
| 8 | 奶奶 | Grandmother | 花白发髻、开衫 |
| 9 | 店员 | Shop apron | 超市绿围裙，和田里的人拉开 |

点哪款立刻换到农场上，写入存档。不弹强制向导。标题：「农户形象」。说明一句：「这是你在农场里走动的样子。」英文：`This is how you look on the farm.`

## 闲逛怎么走

人不是一直迈步。走到一个空草地格子，站 2–4 秒（播站着），再换下一个空格。

可走：已拥有的草地（含玩家刷的小路）。  
不可走：已解锁菜地、建筑占地、水塘、地图外。

出生点：有「我的家」就站家门前一格草地；否则站已解锁菜地附近的草地；再没有就用地界中心。

## 别人用哪一款

函数（全场共用，和菜摊头像同一套哈希）：

```
lookFromUid(uid):
  没有 uid → 1
  h = 0
  对 uid 每个字符：h = (h * 31 + charCode) >>> 0
  返回 (h % 9) + 1
```

真玩家若公开档案里有合法 `farmerLook`（1–9），用那个；否则用 `lookFromUid`。  
匿名菜摊客人：1。  
拜访：用那家公开的 `farmerLook`，没有就 `lookFromUid(那家uid)`。

同一账号每次来都是同一款。

## 贴图

每人设 **一张** 表：`src/assets/images/farmers/p_farmer_{id}.webp`（id 1–9）

- 4 行 × 6 列，无分割线。行：`idle` / `walk` / `water` / `harvest`
- 每格约 128×160 CSS 像素源；脚底对齐同一条基线
- 透明底，四角 alpha=0。图里不画草地、不画长影（游戏用现有 `_shadow`）
- 叠在 `#7eaa3d` 草地上不能出现黑方块
- ¾ 侧面，只画朝右前的一侧；朝左用水平镜像
- `walk` 必须腿轮流迈，第 6 帧能接回第 1 帧
- `water` 要看出在倒水；`harvest` 要看出在摘
- 儿童（5、6）按孩子的头身比画在格里，禁止把成人缩小充数

**不进 Service Worker 预缓存。** 本站预缓存只收 HTML/CSS/JS/JSON；图是按需加载（房子、汽车已经这样）。农户表走同一套 `_lazyImg`。弱网缺图时，这个人退回现有色块 `_drawVillager`，游戏照常可玩。

## 运行时（只活在内存，不写存档）

自己场上一个农户；菜摊有客时再加一个站桩客人。

农户：

- `look` 1–9、`gx gy` 浮点格子、`face` `'l'|'r'`
- `anim`：`idle` | `walk` | `water` | `harvest`
- `task`：空 = 闲逛；有则走到目标地块再播对应动作，播完清空

深度和房子、菜一起按 `gx+gy` 排。人站在菜地前时画在菜的前面。  
点击仍先中菜地/建筑/装饰，农户不抢点。

显示身高：成人约 `th * 1.55`（与现在路人尺子一致），儿童约 `th * 1.15`。  
动画 8–12 fps。弹窗开着时现有主循环会停，人冻住，关掉继续。

拜访期间 `_visitLock` 已禁止存档。拜访场上的人用**主人**的 look，不写进访客存档。

## 存档与云

本地增加标量，不升 `save.version`：

```
farmerLook: 2    // 非法或缺失 → 2
```

`_buildPayload()` 带上 `farmerLook`，随现有 60 秒防抖推到 `farm_players/{uid}.gameStats`（公开、非 PII）。游客不写云。

菜摊真实客人池在拼 `who` 时抄对方的 `gameStats.farmerLook`（有就用）。

## 验收

1. 自己农场能看见油画人；闲时走走停停，不踩菜地和房子。
2. 点熟菜：人走到、摘完，菜才进仓。连点两块则先摘完第一块再去第二块。走到时仓满则这块不进仓。
3. 打理里点浇水：人走到、倒完水，时间才缩短。已浇过/已熟不排队。
4. 设置九宫格能换 9 款，当场变、刷新还在。
5. 菜摊客人是油画人 + 原气泡；匿名用男农户。
6. 拜访看到的是那家的形象，回来自己的形象没被改掉。
7. 九张表叠草地无黑底；儿童明显矮。
8. 老存档摊、仓、田坐标不变。
9. 相关 JS `node --check` 通过；手机 360px 宽能认出走、浇、摘。
