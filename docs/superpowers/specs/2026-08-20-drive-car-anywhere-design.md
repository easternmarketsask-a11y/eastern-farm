# 开车去任意地方（2026-08-20）

农场里点哪儿，人就去哪儿。有车就能坐上车开过去，贵的车开得快。

起因是 Chris 问「汽车在哪里买」——车早就能买（商店 🚗 汽车，16 款 200–62000 币），
但买回来只是停在地上加魅力值，**人上不去、车不会动**。这份设计把车从摆设变成能开的。

顺带修掉的事：商店 7 个页签在 390px 手机上塞进一条隐藏了滚动条的横滑条，
只露得出前 4 个，**扩建 / 房子 / 汽车三个在屏幕外**且没有任何「右边还有」的提示——
Chris 因此以为「商店里根本没有汽车页签」。已改为换行两行全露（`commit a6232a2`）。

## A 期（本期做）✅ 已上线 2026-08-20

### 玩家看到什么

| 玩家做什么 | 发生什么 |
|---|---|
| 点农场里任意空地 | 人**绕开**菜地/房子/水塘走过去（现在点空地毫无反应）|
| 点场上停的车 | 面板顶部多一个「🚗 上车」（原有的换车款保留）|
| 点「上车」 | 人走到车边，坐进去。人不见了，车归你开 |
| 驾驶中点任意一处 | 车绕开障碍开过去，到了人下车站在车旁 |
| 驾驶中再点这辆车 | 按钮变「🚶 下车」，就地下车 |
| 驾驶中点菜地 | **自动下车**去干活，不会把人困在车上 |

### 车速（Chris 2026-08-20 选定：贵的车开得快，仅此而已）

车款价差 = 速度差。不加载货、不加别的属性，本期就这一条。

| | 格/秒 | 相对走路 |
|---|---|---|
| 走路 | 2.2 | 1× |
| 农用（旧皮卡 200 – 冷藏车 3,800）| 4.4 | 2× |
| 家用（4,500 – 9,000）| 6.0 | 2.7× |
| 越野（11,000 – 20,000）| 7.5 | 3.4× |
| 豪华（24,000 – 62,000）| 9.0 | 4× |

速度按 `CAR_LEVELS[].cat` 取，四档写死在一张表里，改数值不用动逻辑。

### 🔒 几条定死的规矩

1. **「人在车里」不写进存档**。刷新页面自动下车。存档里只有车停在哪，没有「谁在车上」这种
   需要复原的中间态——存档坏了要修人，代价远大于省下的这点便利。
2. **车真的换停车位**。开到哪停到哪，写进 `map` 那条记录的 `gx/gy` 并存档。不是开完弹回原位。
3. **点了上车就立刻去**。手上的农活队列清空（正在做的那一下做完），不留半截状态。
4. **建造模式、拜访别人农场（`_visitLock`）一律开不了车**，点空地也不走。别人的农场不是你的地。
5. **只在自己已解锁的地里走**。没解锁的地、水面、菜地、建筑占的格子都不可走。

### 怎么实现

**新文件 `src/js/pathfind.js`** —— 网格寻路（BFS，4 邻接）。

现在人物移动是 `moveToward()` 直线插值，近距离没事；一旦「点任意地方」，
**人会从水塘和房子里直接穿过去**。所以寻路是本期的前提，不是可选项。

- 可走判据复用 `farmer.js` 的 `cellWalkable`（已解锁 + 非菜地 + 非建筑 + 非水）
- **开车的判据更严**：车占 `w×h`（豪华 3×2、加长礼车 4×2），
  以候选格为锚点的整个车身范围都要可走，否则不算可走
- 目标不可达 → 走到 BFS 过程中**最接近目标的可达点**，不原地不动、不报错
- 农场最大也就几十格见方，BFS 开销可忽略，不做 A*

**改 `farmer.js`**
- 新 job 类型 `{kind:'goto', gx, gy}`，走 `A.path`（路径点数组）逐段 `moveToward`
- `A.driving = mapIdx | null`（**只在内存，不落盘**）
- 驾驶中速度取车款档位，走路仍是 `WALK_SPEED`
- 农活指令（harvest/water/plant）入队时若在驾驶中 → 先自动下车

**改 `mapview-iso.js`**
- `_openCarPanel` 顶部加「🚗 上车 / 🚶 下车」按钮
- 点空地分支：`_tapCell` 遇到非菜地时不再直接 return，改为派 `goto`
- 驾驶中的画法：人不画，车按 actor 的实时位置画（不是 map 里那条记录的位置）
- 到达后回写 `map[idx].gx/gy` + `Farm.state.save()`

**不碰**：存档结构、云同步、登录、积分、Firestore 规则。

### 验收（跑不通就不叫做完）

新增 `scripts/verify/car-drive-tests.js`（由 `cdp.mjs` 在页面里执行）：

1. 点空地，人真的移动了（坐标变化）
2. 构造一个必须绕路的场景，路径**不穿**水/建筑/菜地
3. 四档车速真的不同（同距离耗时分档）
4. 开完车 `map` 里那条记录的 `gx/gy` 变了，且存档里也变了
5. 拜访模式 / 建造模式下点空地和上车都无效
6. 刷新后不在车上（驾驶态没落盘）

进 `deploy.sh` 的发布闸门（**闸门 I**，约 35 秒）。

**上线实测（2026-08-20，生产站 farm.easternmarket.ca）**：
`car-drive-tests.js` 全 33 条断言 `failures: []`；实跑一趟车从 `(0,7)` 开到 `(4,6)`、
写进存档、人下车站在 `(3,8)`。车面板的「🚗 上车」按钮已截图确认。

**实现过程中查出并修掉的两个坑**（只有真开起来才暴露，都不抛异常）：
1. **车自己就是一个 building** —— `cellWalkable` 不排除它的话，车脚下那格永远
   「不可走」，寻路起点直接失败，`goTo` 恒返回 false。→ `cellWalkable` /
   `walkableFor` 加 `exceptIdx`。
2. **闲逛逻辑会把整辆车挪走** —— `tick` 的 idle 分支是给人写的，驾驶中无任务时
   它照样派 `idlewalk`，车自己开着到处溜达。→ 有车在身且无任务时保持静止。

## A+1 开车自动干农活 ✅ 已上线 2026-08-20

派农活时，人自己判断该走过去还是去开车。

### 判据：算出来的，不是拍脑袋定的阈值

农场就这么大，车常停在另一头 —— 跑去开车再开回来，可能比直接走还慢。所以每次真算一遍：

```
直接走过去 = 人到地头的寻路格数 ÷ 2.2
开车过去   = 人到车旁的格数 ÷ 2.2  +  车到活儿附近的格数 ÷ 车速  +  下车后剩几步 ÷ 2.2
开车快过 DRIVE_WORTH_IT(1.3) 倍才开车
```

车越贵（越快）越容易划算，**不用调任何参数**，玩家买贵车自然感觉得到。

- **只判一次**：这批活刚开工时算，开车只负责去干活的第一段路。菜地连片挨着，
  逐块上下车太吵。
- **开车的目标允许停不到地头**：干活的落脚点紧贴菜地，2×2 甚至 4×2 的车身根本
  放不下。车停最近能停的地方，剩下几步走过去。⚠️ 早先要求「精确到达」，
  结果每辆车都被判成到不了，**自动开车永远不触发**。
- 判据摊在 `Farm.farmer._driveDebug(plotIdx)` 里，调参和排查都看它。

### 🔒 到了不自动下车（Chris 2026-08-20）

「不要自动下车，点一下车才下车」。开一段就被踢下车、想接着开还得走回车边，很烦。
**唯一例外**：开车本来就是为了去干活 —— 不下车干不成活。

### 顺带修的两个真 bug

1. **农活的移动原本是直线插值**。地块近时看不出来，开车把距离拉长后会明显穿墙
   穿水塘。现在农活也走寻路。
2. **人脚下那格永远算可走**（`freeFromHere`）。车身完全可能盖在人身上（车停过来、
   人走过去都会），那时寻路起点不可走，`find()` 返回 null，「走多久 / 开车值不值」
   全成无穷大，自动开车**静默失效**。你已经站在那儿了，从那儿出发当然可以。

### 上线实测（2026-08-20，生产站，手机视口 390px）

```
failures: []
自动开车判据：走路 3.64s / 阈值 2.80s / 选中 9 号车
车实际移动：(1,6) → (5,7)，离活儿从 8 格缩到 3 格
```

⚠️ **F3 那条断言曾经是假通过**：判据写成「车离地块 10 格以内」，车停在原地没动
也满足 —— 自动开车根本没触发时它照样绿灯。现在改成「车动了**且**离活儿更近了」。
写验收断言时警惕这种「不做也能过」的判据。

⚠️ 测试凭空 push 车进 map 时可能盖住人把他围死（真实游戏里人会自己走开），
`manClearOf()` 负责放车前把人挪出车身，否则测试随机红。

### A+5 车辆保养（奖励型，2026-08-21 Chris 定）

Chris：「咱不要惩罚型。」没有油、不会坏、永远开得了。

- `map[].shine` 0–1，默认 0＝目录速度（闸门 I 的 4.4 / 9.0 不漂）
- 擦亮（50 农场币）：人走到车旁弯腰擦一会儿，`shine = 1`，开车最多再快 22%
- 开车过程中 shine 慢慢掉回 0，掉完只是回到原来的速度
- 入口：车顶 ✨（点车子本体仍是上车）或商店汽车页「给××擦亮」
- 不加载货格（那是 A+2）
