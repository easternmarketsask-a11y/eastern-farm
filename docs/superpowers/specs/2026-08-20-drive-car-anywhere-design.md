# 开车去任意地方（2026-08-20）

农场里点哪儿，人就去哪儿。有车就能坐上车开过去，贵的车开得快。

起因是 Chris 问「汽车在哪里买」——车早就能买（商店 🚗 汽车，16 款 200–62000 币），
但买回来只是停在地上加魅力值，**人上不去、车不会动**。这份设计把车从摆设变成能开的。

顺带修掉的事：商店 7 个页签在 390px 手机上塞进一条隐藏了滚动条的横滑条，
只露得出前 4 个，**扩建 / 房子 / 汽车三个在屏幕外**且没有任何「右边还有」的提示——
Chris 因此以为「商店里根本没有汽车页签」。已改为换行两行全露（`commit a6232a2`）。

## A 期（本期做）

### 玩家看到什么

| 玩家做什么 | 发生什么 |
|---|---|
| 点农场里任意空地 | 人**绕开**菜地/房子/水塘走过去（现在点空地毫无反应）|
| 点场上停的车 | 面板顶部多一个「🚗 上车」（原有的换车款保留）|
| 点「上车」 | 人走到车边，坐进去。人不见了，车归你开 |
| 驾驶中点任意一处 | 车绕开障碍开过去，到了人下车站在车旁 |
| 驾驶中再点这辆车 | 按钮变「🚶 下车」，就地下车 |
| 驾驶中点菜地 | **自动下车**去干活，不会把人困在车上 |

### 车速（Chris 2026-08-20 选定：贵的车开得快，仅此而已）

车款价差 = 速度差。不加载货、不加别的属性，本期就这一条。

| | 格/秒 | 相对走路 |
|---|---|---|
| 走路 | 2.2 | 1× |
| 农用（旧皮卡 200 – 冷藏车 3,800）| 4.4 | 2× |
| 家用（4,500 – 9,000）| 6.0 | 2.7× |
| 越野（11,000 – 20,000）| 7.5 | 3.4× |
| 豪华（24,000 – 62,000）| 9.0 | 4× |

速度按 `CAR_LEVELS[].cat` 取，四档写死在一张表里，改数值不用动逻辑。

### 🔒 几条定死的规矩

1. **「人在车里」不写进存档**。刷新页面自动下车。存档里只有车停在哪，没有「谁在车上」这种
   需要复原的中间态——存档坏了要修人，代价远大于省下的这点便利。
2. **车真的换停车位**。开到哪停到哪，写进 `map` 那条记录的 `gx/gy` 并存档。不是开完弹回原位。
3. **点了上车就立刻去**。手上的农活队列清空（正在做的那一下做完），不留半截状态。
4. **建造模式、拜访别人农场（`_visitLock`）一律开不了车**，点空地也不走。别人的农场不是你的地。
5. **只在自己已解锁的地里走**。没解锁的地、水面、菜地、建筑占的格子都不可走。

### 怎么实现

**新文件 `src/js/pathfind.js`** —— 网格寻路（BFS，4 邻接）。

现在人物移动是 `moveToward()` 直线插值，近距离没事；一旦「点任意地方」，
**人会从水塘和房子里直接穿过去**。所以寻路是本期的前提，不是可选项。

- 可走判据复用 `farmer.js` 的 `cellWalkable`（已解锁 + 非菜地 + 非建筑 + 非水）
- **开车的判据更严**：车占 `w×h`（豪华 3×2、加长礼车 4×2），
  以候选格为锚点的整个车身范围都要可走，否则不算可走
- 目标不可达 → 走到 BFS 过程中**最接近目标的可达点**，不原地不动、不报错
- 农场最大也就几十格见方，BFS 开销可忽略，不做 A*

**改 `farmer.js`**
- 新 job 类型 `{kind:'goto', gx, gy}`，走 `A.path`（路径点数组）逐段 `moveToward`
- `A.driving = mapIdx | null`（**只在内存，不落盘**）
- 驾驶中速度取车款档位，走路仍是 `WALK_SPEED`
- 农活指令（harvest/water/plant）入队时若在驾驶中 → 先自动下车

**改 `mapview-iso.js`**
- `_openCarPanel` 顶部加「🚗 上车 / 🚶 下车」按钮
- 点空地分支：`_tapCell` 遇到非菜地时不再直接 return，改为派 `goto`
- 驾驶中的画法：人不画，车按 actor 的实时位置画（不是 map 里那条记录的位置）
- 到达后回写 `map[idx].gx/gy` + `Farm.state.save()`

**不碰**：存档结构、云同步、登录、积分、Firestore 规则。

### 验收（跑不通就不叫做完）

新增 `scripts/verify/car-drive-tests.mjs`，复用现有 `cdp.mjs` 无头 Chrome：

1. 点空地，人真的移动了（坐标变化）
2. 构造一个必须绕路的场景，路径**不穿**水/建筑/菜地
3. 四档车速真的不同（同距离耗时分档）
4. 开完车 `map` 里那条记录的 `gx/gy` 变了，且存档里也变了
5. 拜访模式 / 建造模式下点空地和上车都无效
6. 刷新后不在车上（驾驶态没落盘）

进 `deploy.sh` 的发布闸门。

### ⚠️ 关于「油耗车损」的关切（记在这里，排到它时再定）

这游戏现在的调性是**打开就轻松**。加油和修车是**惩罚型**机制：玩家忘了加油就寸步难行，
而主要客群是华人家庭、中老年顾客和小孩——最容易被这类设计劝退的人群。

同样的玩法深度可以做成正向的：

- **惩罚型**：油会耗尽，没油开不了，要花钱加油；车会坏，坏了不能开
- **奖励型**：保养过的车跑得更快 / 多一格车斗；不保养只是回落到基础速度，**永远不会不能用**

排到 A+5 时给 Chris 两个方案对比，由他定。本文件不预设结论。
