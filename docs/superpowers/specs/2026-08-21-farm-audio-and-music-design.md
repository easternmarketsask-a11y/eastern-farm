# 农场声音：混音总线 + 背景音乐（2026-08-21）

Chris：「一定要高档专业的音效，要给我的玩家最佳体验」「农场需要氛围音乐」。

## 一、音效：缺的不是音色，是混音

音色那层（土扑+细沙、叶片窸窣、水流气泡、铃钟的非谐分音）本来就不差。
真正缺的是**整条混音链**——所有声音干巴巴直连输出：没有空间、没有峰值控制、
高频全是毛刺、而且全挤在正中间。这才是「廉价合成音」和「高档音效」的分界。

三级总线，全部程序化，**零音频文件**（保持首访体积不变）：

| | 做什么 | 听感 |
|---|---|---|
| `shape` highshelf −3.5dB @8k | 削合成波形和噪声的毛刺 | 不是变闷，是不刺耳 |
| 混响（程序化 IR 0.55s） | 声音落在院子里 | 不是教堂也不是浴室：短、暗、8ms 预延迟 |
| `glue` 压缩器 −18/3:1/软膝 24 | 峰值控制 + 胶合 | 连点收获不再发糊发炸 |

- **IR 是算出来的**：指数衰减噪声 + 一阶低通调暗 + 预延迟，两声道各自随机＝天然立体声宽度
- 🔒 **同一个声音事件的所有层必须共用同一个声像值**，否则一次收获会像从两边同时传来，声音散架。
  唯一例外是浇水的气泡（本来就是四散的水滴）
- 🔒 **UI 音（点击、错误）走 `dryGain` 不进混响**——点击带混响显得迟钝，而它一天响几百次

### 喇叭与发动机（Chris：喇叭要响、发动机要真实）

- **喇叭**原来挂了 `lowpass 900`，把谐波全削光了 —— 而喇叭的穿透力恰恰在 1–2kHz。
  现在保留到 3.6k、起振 2ms、响度翻倍，双音仍是小三度（真车就是两个簧片）。
- **发动机**原来是「三角波 + 滤波噪声」＝嗡嗡声，像冰箱。内燃机的声音本质是
  **一串规律的爆发**：四缸四冲程每两圈点火四次。现在合成一个「一个工作循环」的
  脉冲 buffer 循环播放，每次点火 = 爆音 + 排气管腔余振，**四次点火的强弱和时刻各差
  几个百分点**（完全均匀立刻听出是电子合成）。加速靠 `playbackRate`＝脉冲变密，
  不是音调平移。转速跟车速走：皮卡低沉，豪华车高亢。

🔒 **发动机响度必须按 RMS 定，不能按峰值。** 脉冲信号峰值 1 但 RMS 只有 0.26，
波峰因数 11.7dB。按峰值调出来的 `gain 0.17` 实测有效 RMS 只有 0.0079，
**比喇叭轻 12 倍 = 听不到**。现在 0.62，落在喇叭响度三成。
⚠️ `startEngine` 之前还漏了 `ctx.resume()`（`play()` 有）——玩家第一个动作就是开车时，
音频上下文根本没启动，静默无声。

## 二、背景音乐：程序化生成，按日历自动切

**为什么不放 mp3 loop**：两分钟 loop 即便 128kbps 也要 2MB，而首访已经要下 ~600KB
（CLAUDE.md 标着「弱网新客人依旧慢」）。程序化体积为零、永不重复、还能跟游戏状态联动。

**怎么不像廉价 MIDI**：音色是叠出来的（拨弦有非整数倍泛音和触弦噪声、垫音是失谐振荡器
叠的合唱感、笛音有气声和浅颤音）；五声音阶没有半音冲突，随机组合也不会难听；
慢、留白多；时值力度声像都带随机，不做机械等分节拍。
调度用 lookahead（`setTimeout` 只负责「该往前排了」，音符时刻一律用 `ctx.currentTime`
精确排期）——直接用 setTimeout 触发音符会抖得很明显。

### 🔒 风格＝一条数据，不是一段代码

七款：**中式田园**（日常）/ 春节 / 中秋 / 丰收季 / 雨天 / 西式民谣 / 极简氛围。
加一款只是往 `STYLES` 加一条（音阶、根音、疏密、音色配比）。写死成分支的话，
每逢节日都要改代码重新部署。

中式那几款的区别不只是快慢，**调式换了**：日常 C 宫（平稳温暖）、春节 G 徵（明亮）、
中秋 A 羽（清冷）——这才是中国音乐里决定情绪的东西。

疏密梯度（平均每簇间隔）：丰收 2.1s < 春节 2.5s < 日常 3.4s < 西式 4.0s <
中秋 5.6s < 雨天 6.9s < 极简 9.8s。

### 自动选曲（Chris 2026-08-21 选「按日历自动切，不用我管」）

优先级：**临时指定 > 节日 > 真在下雨 > 日常**。

- 节日走游戏现成的 `events.js`（`activeFestival.id` → `FESTIVAL_STYLE`），**不自己造农历表**
- 雨天走 `weather.js` 的**萨斯卡通实况**（Open-Meteo）——真下雨才放，不假装
- 每 15 分钟重判一次（节日会跨日、天气会变），风格变了平滑切换
- **临时指定**是留给 Chris 的后门：`?music=harvest` 打开一次就记住，`?music=auto` 清掉。
  全自动的玩家碰不到它。

默认**开**但很轻（音乐总线 0.6 × 主音量 0.18，垫音 gain 0.10 ⇒ 约音效峰值的 11%），
设置 → 声音 里可单独关（存档字段 `musicOff`，老存档无此字段＝开）。
音乐总线接在音效总线上，所以它也走那层院子混响和胶合压缩，和音效在同一个空间里。

## 三、工具修复

🔒 `scripts/verify/cdp.mjs` 加了 **`--autoplay-policy=no-user-gesture-required`**。
没有它，合成的 `pointerdown` 不算「真实用户激活」，AudioContext 永远停在 `suspended`，
**任何音频测试都测不到实际出声**（会误判成功能坏了）。
⚠️ 同理：`element.click()` 不触发 `pointerdown`，而音频解锁监听的正是它——
测试里要显式 `dispatchEvent(new Event('pointerdown'))`。
