# 设计文档：邻里偷菜 + 作物打理（社交攀比 + 核心循环加深）

> 日期：2026-06-09
> 项目：Eastern Farm 东方农场（farm.easternmarket.ca）
> 北极星：**让客人玩得开心 → 对东方超市产生粘性。** 娱乐性是手段，粘性是目的。
> 本轮代号：方向①（社交攀比 / 偷菜）。方向③（真超市引擎）后续单独立项。

---

## 1. 背景与判断

### 1.1 客人反馈与诊断

客人反馈「游戏不够吸引」，进一步定位为两类症状：

- **B「玩一下就觉得就这样」** —— 核心动作没意思、看穿得快。
- **C「玩过几次不再回来」** —— 没有让人天天惦记的钩子。

**反直觉的根因（代码核查得出）**：游戏**不缺功能**。这一年已堆了大量奖励机制——连击、加速券、双倍化肥、金疙瘩暴击、周末双倍、每日转盘、七日签到、读新闻领币、特价种子、走访邻居、仓库配送、成就、天气、社区排行、晒卡。

问题在于这些**全是「奖励」，不是「玩法」**。玩家真正动手做的，从头到尾只有：**点空地 → 选种子 → 等 → 点收获 → 配送**。这中间：

1. **没有需要动脑的选择**：种什么都行、菜不会坏、钱总是够，每个动作都没有「选择」和「后果」。
2. **没有想达成的目标/梦想**：升到 Lv10 拿称号就到头。
3. **奖励全是「天上掉的」**（暴击/转盘/签到），不是「努力挣来的」。

结论：像一台老虎机——光声奖励一开始爽，但玩家**没有主导权、也没在追求什么**，新鲜感一过就腻。**奖励是「滴」，缺一根「脊柱」。**

### 1.2 与上一轮（2026-06-07 每日留存包）的关系

上一轮（PWA / 推送 / 7 天签到 / 倒计时）解决的是「**让人每天打开**」——对关闭状态的玩家施加拉力。本轮解决的是「**打开之后好不好玩、留不留得住**」——补玩法的脊柱。两者互补，不重叠。

### 1.3 本轮范围（已与 Chris 确认 2026-06-09）

| 模块 | 做 | 说明 |
|---|---|---|
| **打理系统**（浇水 + 施肥） | ✅ | 给核心循环加「动脑 + 每次进来有事做」，**可选加成、不强制、不惩罚** |
| **偷菜核心**（被偷 + 主动偷） | ✅ | 经典华人农场留存引擎，治 C（牵挂）+ B（戏剧性） |
| **回家小报**（离开归来结算） | ✅ | 谁顺了你的菜、谁帮了你 → 让「该回来了」可感知 |
| **讨回来 / 复仇循环** | ✅ | 小报直达小贼农场偷回更多 → 社交动力 |
| **防御道具**（看家狗等） | ✅ | 花农场币护菜 = 有取舍的选择 + 农场币出口 |
| **AI 邻居（够真）** | ✅ | 人少阶段撑场子；本地确定性模拟，会种/会熟/会被偷/会来偷/会回应 |
| 真人好友互偷（Phase 1b） | ⏳ 本轮不做 | 需把真实菜地同步到云端，工程更大；1a 验证有效后再做 |
| 服务器端全局 AI 模拟 | ❌ 不做 | 成本高、开发久，人少阶段不值得 |

## 2. 关键设计原则（必读，决定调性与可行性）

### 2.1 分寸红线（防止「品牌游戏让顾客觉得被抢」翻车）

这是一个**超市品牌**游戏，绝不能让顾客对店产生「被抢」的负面情绪。偷菜必须做成「邻里串门的小馋嘴」，不是「损失」。硬性约束：

1. **小额 + 有上限**：一次离开，最多被顺走 `RAID_MAX_PLOTS = 2` 块地的菜（12 块地的农场，默认值，可调）。绝不会回来发现被搬空。
2. **仓库绝对安全**：已收进仓库的菜永不被碰。**只有「熟了你没收」的菜会被顺**——话术是「你没收，被邻居尝了鲜」。
3. **短暂离开不被偷**：离开不足 `RAID_MIN_AWAY = 2h` 一律不触发偷菜（快速查看永远安全、零焦虑）。
4. **净占便宜**：数值上保证「你能主动偷到的」 >> 「你被偷走的」。玩家净感受是占便宜，不是吃亏。
5. **可爱话术**：全程「顺走 / 尝鲜 / 小馋嘴 / 来串门」，**禁用「偷 / 抢 / 盗」负面词**。（内部代号叫偷菜，对顾客不这么叫。）
6. **可防御**：花农场币买道具能大幅减少甚至挡住被偷 → 玩家有掌控感。

### 2.2 打理系统：可选加成，不是必需（避免变成杂活/压力）

经典农场「浇水是必需的（没水就停长）」会增加黏性，但**极易变成枯燥杂活 + 压力**，对妈妈客群是雷区。本设计：

- **不浇水，菜照样长；不施肥，照样收**（不惩罚、不停滞，保持治愈底色）。
- 浇水 / 施肥只是**让用心打理的人多得好处**（更快 / 更多）。
- 因此它给了核心循环「动脑 + 每次进来有事做」，又不沦为强制杂活。

### 2.3 AI 邻居：本地确定性模拟，但要「够真」

- **本地确定性**：AI 邻居不连服务器、不花钱、离线也能玩。同一个「王阿姨」在同一玩家这里**永远是同一个人、同一套作息**（farm 状态 = `f(seed, now)` 的纯函数）。
- **够真**（Chris 的硬要求）：有固定身份/性格、农场跟真实时间在长、随天数慢慢升级、会真的来顺你的菜、会对你的行为有回应。详见 §3.6。
- **历史决策反转（重要）**：现有 `neighbors.js` 曾**特意删掉假玩家**（"邻居卡去掉假玩家"），宁可显示「还没邻居在线」。本轮在 Chris 确认「AI 够真就接受」的前提下**反转该决策**，重新引入高质量 AI 邻居。真人会员与 AI 邻居在 UI 中**混合呈现**（今日 3 邻居 + 排行榜）。

### 2.4 遵守项目铁律

- **两币分离（术语 + 经济）**：游戏有两种货币——**农场币**（充裕，买种子/化肥/道具）与**超市积分**（稀缺，对接真实优惠券）。本轮偷菜/打理的经济**只用「农场币 + 作物」，不产出也不消耗「超市积分」**——让超市积分保持「自己真实经营赚来」的稀缺与珍贵，绝不靠偷别人的菜来稀释它（与「积分珍贵/只读」一贯口径一致）。文案统一用「农场币」，**禁用「金币」**。
- **单一数据源 / 统一模板**：施肥要和现有 `activeEffects.bumperCharges`（高级化肥=双倍收获）对齐，不能两套并存（见 §3.1 + §6）。偷菜/打理的作物状态读写统一走 `Farm.crops` + `Farm.state`，不另起炉灶。
- **存档是神圣的**：新增字段必须升 `save.version` + 写迁移，绝不清空老玩家进度（见 §4）。
- **双语全覆盖**：所有新文案进 `data/i18n.json`，跟随用户语言。
- **治愈系视觉**：动效复用现有体系，不引入高饱和霓虹/闪烁。

## 3. 模块设计

> 以下数值均为**保守默认值，已替 Chris 定，上线后看反应再调**。

### 3.1 打理系统：浇水 + 施肥

**浇水（免费，注意力机制）**
- 每块**生长中**的作物，**每个生长周期可浇水 1 次**；浇水使剩余生长时间**减少 `WATER_SPEEDUP = 20%`**。
- 免费（不消耗资源）——它考验的是「来得勤」，不是「囤道具」。
- 视觉：浇过水的作物显示 💧 水光 + 进度条跳进一格。
- **社交意义打通**：好友 / AI 帮你浇水，**真的对你的作物生效**（同样的提速）。这让现有「帮浇水」从「只给帮忙者发农场币的空动作」变成**一份真礼物**，也给社交加了「互助」这一善面，平衡偷菜的竞争面。（实施前须核实 `firebase-game-sync.js` 的 `sendHelp` 现有逻辑，见 §6。）

**施肥（农场币消耗，投资决策）**
- 商店出售 🌟 化肥（农场币购买 = 农场币出口）。
- 施在某块作物上 → 该块**产量翻倍**（入库 2 棵而非 1 棵）。默认采用「产量翻倍」（对接现有 `bumperCharges` 双倍收获语义、收敛最干净、与偷菜赌注咬合）；「售价 +X%」作为备选不在 V1 默认采用。
- 视觉：施过肥的作物有金色微光。
- **决策价值**：把化肥投在高价值作物、尤其是可能被偷的菜上 → 与偷菜赌注咬合（施肥的菜更值钱 = 更值得护、也更值得被偷）。
- **与现有 `bumperCharges` 的关系**：现有「高级化肥=双倍收获」是**全局自动**对下一次收获生效。本设计把施肥升级为**逐块主动施用**（有取舍）。两者必须二选一收敛——迁移现有 `bumperCharges` 到新模型，或保留其为「快捷增益」另作区分。**实施前必须先读现有用法再定，不得两套并存**（§6）。

### 3.2 偷菜核心 ——「赌注」与结算

**赌注 = 你地里「已熟、未收」的作物。** 生长中的作物不会被偷（看不出价值、也更温和）。

**被偷（你离开期间，归来时结算）**
- 触发条件：离开 ≥ `RAID_MIN_AWAY = 2h`。
- 结算：从你「已熟未收且未受保护」的地块中，挑最多 `RAID_MAX_PLOTS = 2` 块，由 AI 邻居（1b 起含真人好友）「替你收走尝鲜」。
- 效果：被顺的地块变空（等同于你没来得及收、被邻居收了）。**仓库不受影响。**
- 离开越久越可能吃满上限，但**永不超过上限**。
- 每个小贼附「性格」（馋嘴的偷得勤、热心的基本不偷，见 §3.6）。

**主动偷（你逛邻居 / 好友农场）**
- 进入某农场，看到「已熟」的地块可**顺手偷**，入你的仓库（遵守仓库满判定）。
- 每日总上限 `STEAL_MAX_PER_DAY = 6` 块；每个对象每日上限 `STEAL_PER_TARGET = 2` 块 + 冷却 → 逼你**多逛几家**（= 提升社交活跃），不能薅一家羊毛。
- 保证 `STEAL_MAX_PER_DAY` 远大于被偷上限 → **净占便宜**（§2.1.4）。

### 3.3 回家小报（离开归来结算面板）

进游戏时若距上次活跃 ≥ `RAID_MIN_AWAY`，先弹一张「回家小报」：

- **坏消息（偷菜）**：「🐔 王阿姨路过，顺走了你 2 棵青菜」「😋 隔壁小明尝了你 1 根黄瓜」——每条附小贼头像 + 「**去讨回来 ➡️**」按钮。
- **好消息（互助）**：「💧 李奶奶帮你浇了水，番茄快熟了」「🎁 张大叔送了你 1 棵种子」——延续暖心人设、平衡情绪。
- **若无事发生**：不弹小报（不打扰）。
- 视觉：温馨「邻里公告栏」卡片，复用现有 modal + 动效体系，**不施压、不指责**。

### 3.4 讨回来 / 复仇循环

- 小报上「去讨回来」→ 直达该小贼农场。
- 对「偷过你」的对象，本次主动偷可享**额外宽限**（如临时 +1 `STEAL_PER_TARGET` 或额外提示「就偷这一家、心安理得」）——把负面情绪转成有目标的爽点。
- 这是把「被偷的小不爽」立刻转化为「去偷回来的小动力」的关键闭环 = 社交活跃引擎。

### 3.5 防御道具（花农场币护菜）

V1 控制范围，**只做 1–2 件**，避免数值爆炸：

- 🐕 **看家狗**（主推，复用现有 `epShop` 的 `pet` 装饰类别 → 装饰即防御，一举两得）：
  - 拥有并「在岗」的看家狗，使被偷上限 `RAID_MAX_PLOTS` 降低其防护值（如 -1 或 -2），或**有概率抓住小贼**。
  - 抓住小贼时给个反转爽点：「🐕 旺财逮住了来偷菜的小明，他赔了你 1 棵菜赔礼！」
  - 可设「狗粮」消耗或在岗冷却（农场币出口），planning 时定，保持简单。
- （可选第二件）篱笆 / 稻草人：减少可被偷的地块数。**若时间紧，V1 只上看家狗。**

### 3.6 AI 邻居「够真」实现

**数据**：`data/ai-neighbors.json` —— 约 12 个 AI 邻居，每个含：
- `id`（稳定 seed）、`name_zh/en`、`avatar`、`personality`（`greedy` 馋嘴爱偷 / `kind` 热心爱帮 / `balanced`）
- `activeHours`（作息，如傍晚活跃）、`levelEpoch` + `growthRate`（升级速率）、`cropPrefs`（爱种什么）

**够真的四个支柱**：
1. **农场跟真实时间在长**：AI 农场状态 = `f(seed, now)` 的纯函数——把现有 `generateFarmDisplay()` 从「随机一次性」升级为**时间感知**版，使作物真的随时间播种→生长→成熟。你早上看和晚上看不一样，且**有真实熟了的菜可偷**。
2. **随天数慢慢升级**：`level = f(seed, 距 levelEpoch 的天数)` → 排行榜是活的，每天有微妙变化。
3. **会真的来偷你**：回家小报里的小贼 = 真人 + AI 混合，由 `(你的离开窗口, 该 AI 的 activeHours, personality)` 确定性算出，玩家分不太出真假。
4. **会回应你**：本地记 `aiRelationships`——你帮某 AI 浇了水/点了赞 → 隔天小报里 TA 回送礼物；你偷了某 AI → TA 下次顺你的略多（小心机）。

**整合**：AI 邻居并入现有 `neighbors.js` 的「今日 3 邻居」+「排行榜」，与真会员混排（反转 §2.3 的旧决策）。`viewFarm()` 对 AI 邻居渲染其**时间感知真实农场**并允许偷菜。

## 5. 实施分期与顺序

### Phase 1a（本轮，纯本地 AI，零后端改动）

可任意人气下好玩、可快速上线试水。建议顺序（先地基、后串联、最后调性）：

1. **打理系统 — 浇水**：纯前端 + plot 字段，改动小、立刻给核心循环加「有事做」。
2. **打理系统 — 施肥**：收敛 `bumperCharges`，做逐块施用 + 商店化肥。
3. **AI 邻居时间感知农场**：升级 `generateFarmDisplay()` → 真实可偷的农场 + 升级/作息/性格。
4. **偷菜核心**：主动偷（你→AI）+ 被偷结算（AI→你）+ 上限/冷却/红线。
5. **回家小报 + 讨回来**：串起被偷/互助的归来体验 + 复仇闭环。
6. **防御道具（看家狗）**：护菜决策 + 抓贼反转。
7. **整合 + 调性打磨**：并入 `neighbors.js`、双语、动效、净占便宜数值校准。

### Phase 1b（1a 验证有效后再立项）

- **真人好友互偷**：把玩家真实菜地（`plots[]` 成熟态）同步到云端公开 doc，让真人好友能看见并偷真实的菜；被偷在双方存档间真实转移。需扩展 `firebase-game-sync.js` 的公开 `farm_players` 集合 + 安全规则。
- 触发条件：1a 数据证明偷菜/打理确实拉升了活跃与留存。

5. **`epShop` 的 `pet` 装饰类别**：看家狗如何复用其数据/渲染。

## 7. 非目标（Out of Scope）

- ❌ 服务器端全局 AI 模拟（成本高，本地确定性已够）。
- ❌ 真人实时在线对战 / 互动（人少，异步即可）。
- ❌ 强制浇水/施肥（绝不让作物因缺水停长）。
- ❌ 方向③真超市引擎（真实特价→限时活动、扫小票→大奖励、成就→到店真实惊喜）——后续单独立项。
- ❌ 把被偷做成「肉疼的损失」——本轮坚持小额/有上限/净占便宜。

## 8. 验收总览（Definition of Done）

- [ ] 浇水：生长中作物可浇水 1 次、提速生效、有水光视觉；不浇照常长。
- [ ] 施肥：商店可买化肥、逐块施用、产量/价值提升、有金光视觉；与 `bumperCharges` 收敛为单一模型，无双重逻辑。
- [ ] 帮浇水（好友/AI）真的加速被帮者作物（不再是空动作）。
- [ ] AI 邻居农场随真实时间生长、有真实可偷的熟菜、随天数升级、有性格/作息差异。
- [ ] 主动偷：逛邻居可偷熟菜入仓，每日总/单户上限 + 冷却生效。
- [ ] 被偷：离开 ≥2h 才触发、最多 2 块、仓库安全、可被防御挡住。
- [ ] 回家小报：偷/帮事件正确呈现，「去讨回来」直达且复仇宽限生效；无事不弹。
- [ ] 看家狗：在岗减少被偷 / 抓贼反转可用。
- [ ] 净体验校验：正常玩一天「主动偷到的」明显多于「被偷走的」。
- [ ] 红线全过：无「偷/抢/盗」负面词、短暂离开零损失、仓库永不被碰。
- [ ] 存档升版 + 迁移，老玩家进度不丢。
- [ ] 中英双语全覆盖；iPhone 真机无控制台报错。
