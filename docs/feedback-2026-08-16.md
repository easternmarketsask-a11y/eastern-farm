## 产品

- 菜单「怎么玩」下面多一项「意见反馈」
- 提交后当天第一次发 500 农场币；当天再交仍送到后台，不再发币
- 游客可提交（只拿农场币）；没有会员号的不能发超市积分
- 店主在 StockWise「游戏管理」看列表；点采纳 → +500 超市积分（走 admin adjust-ep，不占游戏每日 500 封顶）
- 采纳前确认：「真店积分」

## 怎么验

1. 打开菜单能看到「意见反馈」，点开能写、能选「遇到问题 / 我有想法 / 其他」
2. 第一次提交：余额 +500，toast 说明今天再交不再发币
3. 当天第二次提交：送到后台，余额不变
4. 少于 8 个字不能交
5. StockWise 游戏管理出现这条；点采纳并发 500 积分后，会员积分 +500，状态变已采纳
6. 游客条：只能标记已读，不能发积分
