## 红线（任何修复不得越过）

- ❌ 东方点经济一律不动（真负债）；农场币可放开。经济类建议→只写进报告给 Chris 拍板
- ❌ 不新增外部依赖/CDN（必要则 vendor/ 内置）
- ❌ 存档格式神圣：改结构必须 version + 迁移，绝不静默重置
- ❌ 不动 POS/StockWise 写路径
- ❌ 部署只走 `bash deploy.sh`，且只在**全部批次验证通过后**执行一次

## 流程

1. **Phase A 审计**（并行 workflow）：11 维度 + 1 个「新玩家盲测」agent，各自跑无头浏览器/截图/读码，
   产出结构化 findings（severity P0 阻断 / P1 重大 / P2 打磨，附 file:line + 修复方向）
2. **Phase B 修复**（按文件域分批，串行批次防冲突）：每批 = 子 agent 修 → node --check → CDP 冒烟
   + 针对性验证 → commit。批间不部署
3. **Phase C 复审**：改过的维度换新 agent 重新打分；<8.5 → 回 B 再修，循环
4. **Phase D 交付**：deploy.sh → 生产实测（含手机视口截图）→ 完整报告给 Chris
