# 整场对齐宣传油画 Implementation Plan

> 对照：`promo/keyart-farm-square.jpg`。一步一档，每档可单独截图验收。

**Goal:** 游戏里看见的农场气质达到宣传油画同一档：金黄昏、开阔草甸、一块垄沟田、圆冠树、土路穿过草地。

**Architecture:** 继续程序化世界（`USE_PAINTED_BG=false`）。不搬老存档的房子/菜地。先改「光、草、林、水、路」这些每帧都画、不进存档的层；再给新号盖更接近油画的默认摆场；最后才动作物贴图。

**Tech Stack:** vanilla JS `Farm.isoView` in `src/js/mapview-iso.js`；资产仍是 `src/assets/images/map/*.webp`。

**Spec:** 本文件 + 已完成的 `docs/plans/2026-08-15-keyart-parity.md`（建造物/成熟菜已过一档）。

## Global Constraints

- `USE_PAINTED_BG` 保持 `false`
- 老存档 `landOrigin` / `map` / `plots` / `clearedCells` 一格不搬
- 东点 = 真店债务，不改经济
- 不 push / 不部署，除非 Chris 说上线
- 验收必须截图并排放，不能只读代码

### 第 1 档：草甸构图（本轮执行）

**Files:**
- Modify: `src/js/mapview-iso.js`（`_drawWildWoods` / `_drawGroundPlane` / `_drawPond` / `_drawGoldenHour` / 天空渐变）
- Test: 本地 `8123` + `scripts/_shot_once.mjs` → `promo/_verify-meadow.png`，与 `promo/keyart-farm-square.jpg` 并放

**验收（必须同时成立）：**
1. [x] 镜头前看得到大片金绿草甸和土路，不再是一堵树墙。
2. [x] 水塘不再像白云；偏青蓝、岸暖。（形状仍是塘，第 2 档再改成左侧溪）
3. [x] 草地比改前更金，没有棋盘菱形。
4. [x] 老存档房子/菜地坐标不变（截图里摊、仓、田还在原位）。
5. [x] `node --check src/js/mapview-iso.js` 通过。

截图：`promo/_verify-meadow.png`（老号）/ `promo/_verify-meadow-front.png`（新号）。未部署。

**做法（锁死，执行时按这个改）：**
- `_drawWildWoods`：删掉 `fillFront` 密林。`gy > owned.y2` 的围裙中央（距地界中线 |gx-midX|<6）不种树；两侧极疏（r1>0.18 跳过）留油画那种边角圆树。
- `_drawGroundPlane`：底色和格子改金绿（约 150/168/70 一带）；`gy > y2` 的围裙用同一套金绿，不再走未开发暗绿。
- `_drawPond`：去掉顶上的奶油白/浅金大停；水面改为青蓝（`#7eb8c4` → `#2d6570`），岸用暖土绿描边。
- `_drawGoldenHour` + 天空：左上暖光略加强，云更粉橙。
- 小白花允许开在围裙草地上（油画近景有雏菊）。

### 第 2 档：新号默认摆场（下一轮）

只给 `!map && mapTerrain==null && 菜地没落格` 的全新号盖油画布局：田在中、摊在路、仓在右、鸡舍/井/温室/水车/灯笼围一圈。老号不戳。front 表整体 +y。

### 第 3 档：田和菜

空土床更接近油画那块深棕连田；节日/未重绘作物去贴纸感。锁地徽章缩小，别压过田。

### 第 4 档：HUD 让路

顶栏/底栏/可收条半透明或收窄，截图时农场占画面的比例更接近油画。功能不撤。
