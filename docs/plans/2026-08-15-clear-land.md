# 开垦农田（2026-08-15）

点贴着自家地的林子或草地，花农场币开成一块可种的田。

## 验收

1. [x] 菜单「开垦农田」或建造里的「开垦」进入开垦模式，贴边格子发亮。
2. [x] 点发亮格：扣币、树消失、出现土床，可马上种菜。
3. [x] 林子外的格子要贴着已有地界；水/路心/房子上不能开。
4. [x] 老存档地界不动；新开的格记在 `clearedCells`。
5. [x] `node --check src/js/mapview-iso.js` 通过。

## 实现要点

- 入口：☰ 菜单「开垦农田」、建造盘「开垦」。
- 价/帽与商城 extra_plot 同一套（200/600/1500/3000，最多 4 块）。
- `clearedCells` 只记矩形地界外新开的格；拜访镜像 `worldLayout.cl`。
- 乡路只挡路心，路旁林子可开（否则南沿全被路墙挡住）。
