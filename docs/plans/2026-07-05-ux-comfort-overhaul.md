# 操作舒适度改造 · UX Comfort Overhaul（2026-07-05）

> 起因：Chris 反馈「界面有很大的改进空间，特别在操作上，玩家有时觉得不舒服」，
> 对标游戏：无尽冬日（Whiteout Survival）微信小程序版的交互手感。
> 本文件是 plan（验收守则 #5）：做完一块 commit 一块，进度可从本文件恢复。

## 对标原则（无尽冬日交互为什么舒服）

1. **镜头永远框住内容**：开局镜头紧贴基地，可交互物占屏 ≥60%；平移有边界回弹，
   永远拖不进空白虚空；有惯性，松手自然滑行减速。
2. **触控目标巨大 + 命中宽容**：可点建筑占屏大；点击按「最近可交互物」吸附，
   不要求像素级精确命中。
3. **待收取 = 悬浮气泡**：有产出的建筑头顶浮一个大气泡（~56px）轻轻上下浮动，
   点气泡或点建筑都能收，一步到位，不开弹窗。
4. **每次点击都有即时反馈**：按压缩放回弹、粒子、+N 数字飞向顶部资源计数器、
   计数器滚动跳字。反馈在 100ms 内出现。
5. **面板是底部抽屉不是居中弹窗**：从底部滑出（拇指热区），点遮罩/下滑关闭，
   永不叠两层弹窗。
6. **连续操作不重复走流程**：收完一个自动引导下一个；批量操作（一键收全部）
   常驻;种植类游戏的金标准是 Hay Day 拖划连种/连收。
7. **有事可做就有红点**，且红点集中在固定几个入口，不满屏乱闪。

## 现状证据（headless 390×844 截图 + 探针，2026-07-05）

- **地块可点区域实测 33×36px**（`isoView.plotScreenRect(0)`），低于 44px 可用性底线。
- 开局默认镜头极远：农田+建筑只占屏幕 ~15%，上下大片空景。
- 12 块地开局只解锁 4 块，可点内容又小又少。
- 首次进入：开屏 → 点开始 → 又叠一个「欢迎来到东方农场」居中弹窗。
- 右上角 +/- 缩放圆钮（桌面范式）；捏合缩放代码存在（`_pinch`）。
- 世界杯 ⚽ 悬浮钮、建造钮、NPC 头像分占三角，底部拇指热区利用率低。

## 摩擦点 Top 12（2026-07-05 审计，按影响排序）

1. 🔴 **「一键全收」胶囊点不动**：`.harvest-status-bar` 设 `pointer-events:none`（style.css:4087），承载 onclick 的 `.harvest-status-center` 没开回 auto。批量收获/仓满入口/签到提示全部失效。
2. **所有面板唯一入口 = 右上角 36px 汉堡**（底栏被 style.css:4044 永久隐藏）；tasks/orders/kitchen/community 无其他入口，拇指热区空置。
3. **种植 O(N) 步无批量**：每块空地 tap→选种 modal→点卡→关（mapview-iso.js:488→shop.js:111），收获 O(1) 种植 O(N) 严重不对称。
4. **tap/拖阈值仅 6px 曼哈顿**（mapview-iso.js:412），手抖即判 pan→「点了没反应」。
5. **canvas 无按压态**：pointerdown→up 之间零视觉反馈。
6. **收获不变现**：入仓后要另开谷仓 deliver 才有钱，新手不知道。
7. **延时弹窗顶掉当前弹窗**：单 #modal 容器 innerHTML 直接替换（ui.js:116），升级弹窗会抽走正读的窗。
8. **触控目标普遍 <44px**：汉堡 36、缩放± 32、modal ✕ 34。
9. **无种子流程上下文丢失**：自动开 shop 买完不回原地块（shop.js:118-122）。
10. **失败提示 toast/modal 混用** + toast JS 2.5s 硬切 vs CSS 2.7s 淡出不同步。
11. **空地菱形命中满 1.0 无缩边**易斜向误触相邻格（mapview-iso.js:473）。
12. **farm.tick 每秒遍历隐藏 DOM 空转**（farm.js:418-462，iso 下纯浪费）。

另：开局镜头极远（农田占屏 ~15%，plot 命中区实测 33×36px）——镜头没有 fit-to-content。
