## Direction contract

THESIS: A warm, playable place for Eastern Market families. The game scene leads and interface elements explain the next action.

OWN-WORLD: Painterly golden farm scenery, deep green controls, cream surfaces, ceramic tableware, soft contact shadows, readable bilingual type and stable numeric HUD values. Preserve the official logo and incumbent farm typography.

STORY: Choose farm or table, start immediately, see the useful next action, complete an activity, and return to the centre. A local recent-game link returns to the last game without parsing player state.

FIRST VIEWPORT: Desktop centre uses a dominant farm scene and smaller ceramic table scene; mobile stacks them with readable bilingual titles. Farm uses a compact safe-area HUD around the existing world. Table places instruction, progress and the current dish around the playable tabletop.

FORM: User-approved scene-led selector and inherited gameplay surfaces; precise approved composition, no random identity replacement. Code-first for interactive app screens. seed: none (user-approved incumbent-world refinement).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
