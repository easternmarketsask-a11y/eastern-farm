# 转盘奖品照片(放这里)

幸运转盘会读这个文件夹里的产品照片。**没放图时自动显示 emoji 占位,不会破图**;
放进去并用对文件名,转盘就显示真实照片。

把以下 4 张图丢进本文件夹(`src/assets/worldcup/prizes/`),**文件名必须一模一样**:

| 文件名 | 奖品 | 来源 |
|---|---|---|
| `ryukakusan.png`   | 龙角散            | 你已有照片 |
| `shaqima.png`      | 沙琪玛            | 需拍一张 |
| `yogurt_orig.png`  | 요구르트气泡饮·原味(红盖) | 你发过的图 |
| `yogurt_muscat.png`| 요구르트气泡饮·青提(绿盖) | 你发过的图 |

## 图片要求(转盘上是小圆图)
- **正方形**最佳(会按圆形裁剪居中);长方形也行,但会裁掉上下/左右边。
- 产品**居中、占满画面**,背景白色或透明都行。
- 边长 **200–400px** 足够(转盘上显示约 46px),别用超大原图拖慢加载。
- 格式 `.png` 或 `.jpg` 均可,但**文件名后缀要写 `.png`**
  (若你只有 jpg,把文件名直接命名成 `ryukakusan.png` 也能显示,浏览器不挑后缀)。

放好后刷新观赛台即可看到真实照片。农场币用的是游戏内统一的金币样式,无需配图。
